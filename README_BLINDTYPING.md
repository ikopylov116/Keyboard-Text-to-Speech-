# BlindTyping — тренажёр слепой печати

Отдельная версия приложения развивается в ветке `ai-blind-typing`.

Проект не использует искусственный интеллект, облачные сервисы или обязательную регистрацию. Логика тренировки, подсчёт скорости и статистика работают локально.

## Возможности первой версии

- тренировки по уровням: начальный, средний, продвинутый;
- русский и английский учебный материал в ядре приложения;
- подсветка правильных и ошибочных символов;
- CPM, WPM, точность и количество ошибок;
- статистика последних тренировок;
- локальное сохранение результатов в JSON;
- свободная печать;
- офлайн Text-to-Speech через `pyttsx3`;
- отдельный сервис озвучивания без блокировки интерфейса;
- настройки скорости и громкости речи;
- архитектура с разделением UI, движка тренировки, хранения данных и TTS.

## Запуск

```bash
python -m pip install -r requirements.txt
python run_blindtyping.py
```

Оригинальная версия пользователя остаётся в `main` и в резервной ветке `user-original`.
